# 0009. 気圧は記録しない

- ステータス: 承認
- 日付: 2026-10-31

## 背景

ADR 0001 は、悪化〜治癒の期間を気圧の変動と突き合わせることを差別化の一つに挙げ、
`Checkin` には将来に備えて `pressure`(hPa と24時間変化)の項目を置いていた。
ADR 0005 も、気圧の取得(Open-Meteo)を将来の候補として挙げていた。

しかし気圧を書き込む UI もコードも作られないまま、型・引数・バックアップ検証だけが残り、
読む人の負担になっていた。

## 決定

**気圧の記録・取得・分析は、将来も実装しない。** `PressureSample` 型、`Checkin.pressure`、
`addCheckin` の `pressure` 引数、バックアップ検証の `pressure` を削除した。

## 結果

**良い方向:**
- 外部の気象 API と通信する予定がなくなり、端末内完結(ADR 0005 / 0008)を例外なく保てる。
  位置情報の許可を求める必要も生じない。
- データモデルから使われない項目が消える。

**代償・要フォロー:**
- 古いバックアップに `pressure` が入っていても、zod が知らないキーとして捨てるので読み込みは通る。
  ただし読み込み後のデータからは消える(もともと値が入る経路はなかった)。
- 気圧と症状の関係を見たい人は、メモ欄に自由記述で書く(例: 「低気圧が来た」)。
